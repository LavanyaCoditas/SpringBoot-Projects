## What is Testing?
- Software testing is the process of evaluating a software application to ensure it meets specified requirements, functions correctly, and is free of defects. Testing verifies that the software behaves as expected under various conditions and identifies issues before deployment
- purpose:
- Ensure quality, functionality, and performance.
- Identify bugs or defects early in the development cycle.
- Validate that the software meets user and business requirements.

## What is Unit Testing?
- Unit testing is a software testing method where individual components or units of a program are tested in isolation to ensure they work as intended

## What is System Testing and Integration Testing?
- System Testing: A testing level that evaluates the entire integrated system as a whole to verify it meets specified requirements.
- Integration Testing: Definition: A testing level that focuses on verifying the interactions between different modules or components of the application.

## White-Box Testing:
- Testing the application with full knowledge of its internal code, structure, and logic
- Tools: Jacoco, Junit
